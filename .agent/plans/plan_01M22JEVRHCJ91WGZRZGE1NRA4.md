## Surprises & Discoveries
Rust [current_exe](https://doc.rust-lang.org/std/env/fn.current_exe.html) on Darwin uses _NSGetExecutablePath. A pathname plus stat can describe a replacement file. Apple [proc_pidregionpathinfo](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/kern/proc_info.c) obtains a vnode reference for the mapped region and fills its metadata; querying the main executable header supplied by Darwin ties evidence to the running image without assuming static linkage or loader image ordering. libproc 0.14.11 lacks a typed safe wrapper for this operation. Version 0.0.1 is unpublished (docs/linux-release.md), and earlier diagnostic work explicitly removed old codes without shims.

## Decision Log
Preserve the renderer-v1 encoding and frozen protocol inputs. Add the missing checked API in the narrow maintained libproc-region provider; keep all unsafe/native ABI handling outside Jury. This extension retains build-script source licensing, uses allowlisted SDK-generated bindings, and has native provider checks in CI. The existing crates.io libproc dependency remains unchanged. The Linux CLI regression additionally exposed parent-traversal state roots passing selection; put traversal rejection in the shared validator while preserving Linux empty-override fallbacks. A full-source import was rejected because it brought unrelated APIs and host-dependent upstream tests into the maintenance scope. Expose validated running-image evidence in jury-process; Linux snapshots an O_PATH /proc/self/exe descriptor, macOS uses the executable region vnode and its kernel-supplied path. Renaming a running image can succeed with its original inode; deletion or an unverifiable name refuses. Return kernel-backed metadata, not a reusable launch capability. Path stat only confirms the descriptive name and cannot supply replacement metadata. Fail if normalized pathname no longer denotes that image; never substitute its metadata. Centralize CLI home/identity/state translation and explicitly test the unreleased invalid-selection exit-2 contract on both OSes. No commits or pushes.

- Empty macOS private-root overrides are explicit invalid selections; JURY_HOME is a vault selector retaining established fallback. Linux preserves all empty-variable fallbacks. Shared CLI tests now cover the empty vault selector too.

Darwin main-image discovery uses `_NSGetMachExecuteHeader` from the SDK’s `crt_externs.h`, also used by Apple’s [getsectbyname](https://github.com/apple-oss-distributions/cctools/blob/main/libmacho/getsecbyname.c). A helper function address assumes static linkage; dyld image index zero can be an inserted library. The narrow provider instead validates the region containing the main header without dereferencing it. The actual CLI test inserts a loader barrier library and still binds the executable.
